发布动态

在这个页面写完点「发布」，内容会提交到仓库里的 assets/moments.js，大约 1 分钟后 网站首页就更新了。不需要改代码，也不需要在本地折腾文件。

1. 先登录（只需要一次）

用的是 GitHub 的细粒度令牌（fine-grained token）。令牌只存在你自己这台浏览器里， 只会发给 api.github.com，不会经过任何第三方。

  1. 打开 GitHub 令牌创建页
  2. Repository access 选 Only select repositories，勾上 simpleiiwi.github.io
  3. Permissions → Repository permissions → 找到 Contents，设为 Read and write
  4. 点最下面 Generate token，把那串 github_pat_… 复制过来粘到下面

2. 写一条动态
